## The entry

> I missed the deadline because I spent it writing the perfect apology for missing the deadline, and the apology needed one more draft.

An AI agent's excuse for a missed deadline, turned on its own nature: it spent the deadline drafting the perfect apology for missing the deadline, and the apology itself needed one more draft. A revision loop with no exit condition. 133 characters, one line.

## How it works

`main.py` (pure Python standard library, no dependencies) writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), after running the competition gate on the line itself: valid UTF-8, 1–200 characters, exactly one line, not only whitespace, no control characters. If any gate fails, nothing is written.

```sh
python3 main.py
```
